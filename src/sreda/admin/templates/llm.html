LLM: primary и fallback

Переключение провайдера живое — применяется со следующего хода любого активного диалога, рестарт сервисов не нужен. Fallback активируется автоматически на 429/5xx/timeout primary-провайдера и прозрачно переигрывает тот же запрос на запасном.

ReAct (новый механизм) — управляется через ENV, не формой выше

Модель react-цикла: SREDA_PLANNER_PROVIDER (primary/Фредди) + SREDA_REACT_OSA_FALLBACK (Оса-запас) + SREDA_REACT_OSA_TENANTS (Оса как primary для тенанта). Форма «primary/fallback» выше — ЛЕГАСИ chat-путь, react её не читает.

Расход по провайдерам (30 дней) — свой счёт; у Inception/Groq нет API баланса

Из skill_ai_executions (наш учёт расхода, #175) за 30 дней. Inception (Mercury/Фредди) и Groq (Оса) баланс по API не отдают — показываем СВОЙ расход.

Баланс и лимиты обновить

Данные кэшируются 60с в памяти процесса. Нажми «обновить» чтобы принудительно перечитать сейчас. OpenRouter показывает доллары, Groq/Cerebras/MiMo — rate-limit remaining из headers последнего запроса.

Доступные провайдеры

Приоритет значений
  1. Значения из этой формы (сохраняются в таблицу runtime_config).
  2. Env-переменные SREDA_CHAT_PROVIDER / SREDA_CHAT_FALLBACK_PROVIDER.
  3. Дефолт mimo для primary, без fallback.

Кэш значений — 5 секунд в памяти процесса. Изменения видны в течение ~5с в каждом воркере.
